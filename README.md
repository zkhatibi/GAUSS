Generative Autoencoders for State-of-the-Art Single-Molecule Magnets (GAUSS) is an automated machine learning framework based on VAEs and RNNs for the automated design of novel and 
record-breaking single-molecule magnets. A full description of the model, including analysis, benchmarking, and discussion of its efficiency, can be found at:
https://arxiv.org/abs/2602.23230
